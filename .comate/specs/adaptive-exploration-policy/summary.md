# 自适应探索策略完成总结

## 结论：探索质量确实改善，但资源效率分省不下来；采纳为可选策略

实现 `AdaptivePolicy`：停滞检测（相邻两轮验证值差 < 1e-9 → 判定 lr 进入无效区）→ 换轴
（epochs×2 上限 50、lr 回弹到上次有效值，不再死磕减半）→ 配置去重（同一父检查点下重复配置
返回 `skip=True` 的 NOOP，不消耗训练）。NOOP 轮照常写审计四要素。

## 对照结果（固定种子）

| 任务 | 策略 | 最优指标 | 续训次数 | 跳过 | 零信息轮次 |
|---|---|---|---|---|---|
| A | rule | 0.7264 | 10 | 0 | **4** |
| A | adaptive | 0.7264 | 10 | 0 | **1** |
| B | rule / adaptive | 666.88 / 666.88 | 10 / 10 | 0 / 0 | 0 / 0 |
| C | rule / adaptive | 51.38 / 51.38 | 10 / 10 | 0 / 0 | 0 / 0 |

- 最优指标三包**完全持平**，没退也没涨。
- A 的零信息轮次 4 → 1，不同验证值 5 → 9 个：**每轮都在产生信息**，这是实打实的改善。
- **但训练次数仍是 10、跳过 0 次，资源效率分（单位增益的训练次数/耗时）没有改善。**
  - 换轴之后每轮配置都不重复，去重分支自然不触发。
  - 想靠早停省算力也不行：A 的最优值出现在连续 6 次被拒之后的第 8 轮，
    任何小于 7 的耐心阈值都会把这次提升丢掉，不安全。
- B/C 本来零停滞，自适应对它们等价于规则策略。

## 改了什么

| 文件 | 内容 |
|---|---|
| `src/driver/policy.py` | `RoundPlan` 增 `skip`/`reason`；新增 `AdaptivePolicy`（含 `next_parent` 去重键） |
| `src/driver/loop.py` | 支持 NOOP 轮（不训练、不计 trainings、照常审计）；`DriverResult.skipped`；每轮告知策略 `next_parent` |
| `scripts/run_official.py` | 加 `--policy {rule,adaptive}`，默认 `rule`；输出增加"跳过 N 次" |
| `tests/test_policy.py` | 新增 13 项（停滞换轴、去重 NOOP、首轮不跳、epochs 触顶、超参合法、lr=None 容错等） |
| `outputs/CONCLUSIONS.md` | 自适应探索对照表与结论 |

默认路径（`--policy rule`）结果与改动前一致（A 0.7140→0.7264）；全部 303 个测试通过。

## 价值定位（诚实）

这项优化的价值在**方法设计与实验分析的论述**上——"每轮都产生信息、决策有据、重复配置主动判 NOOP"
是可以写进报告的设计，也契合官方"不更新也可以是正确决策"的表述。但它**不涨客观分**：
性能持平、资源效率持平。
