# A3 C-MAPSS 回归适配完成总结

> spec: `.comate/specs/a3-cmapss-regression/`
> 完成时间：2026-11-10
> 测试：180 项全部通过（含 A1 分类全部回归验证）

## 做完了什么

把 NASA C-MAPSS 发动机剩余寿命（回归）任务接入了现有闭环，**与 A1 分类共用同一个
`SelfEvolvingLoop`，只换配置**。9 个任务全部完成。

## 核心结果（RMSE，越低越好）

| | E0 静态基线 | E2 规则闭环 |
|---|---|---|
| 综合 RMSE | 30.68 | **22.07** |
| 最差阶段 RMSE | 41.64 | **31.02** |
| 训练 / 上线 | 1 / 0 | 7 / 3 |

进入 FD002/FD004（6 种工况）后静态基线 RMSE 从 ~19 跳到 ~40，闭环一个批次内拉回
~20 并维持。固定种子两次运行一致。

## 架构：扩展而非改写

- 分数方向统一：回归对外用 `score = -RMSE`（越大越好），门控/参照线/恢复速度逻辑
  一字未改。报告层转回正 RMSE。
- 任务类型分支贯穿 model / performance / report / gate / loop，`class_set=None` 走回归路径。
- 适配器工厂 `datasets/factory.py`：新任务登记即可，脚本 `--config` 驱动。

## 过程中修掉的两个真 bug

1. **scaler 维度**：特征子集降维后全维 scaler 快照不匹配 → 加 `IncrementalScaler.subset`。
2. **feature_mask 未在预测时套用**：被提升的特征子集模型预测时收到全维特征，输出崩坏
   （RMSE 冲到 ~100，8 次降级）。把 `feature_mask` 做成模型正式字段，在 `_prep` 里对
   训练和推理统一套用。修好后降级事件归零。

这两个 bug 在 A1 没暴露，是因为 A1 的消融里 FEATURE_SUBSET 从未被提升过。A3 触发了它，
才把问题逼出来——跨任务复用本身就是一种压力测试。
