# 改训练损失（性能最后一搏）

> 加宽与超参都已证明到顶。唯一剩下的合规性能杠杆：**只改训练损失**。
> 官方明确"可修改代码与学习率、批大小、训练轮数等参数"；损失只作用于训练，
> 不碰 `predict.py` 推理路径、不改网络结构与输入 schema，产出的 checkpoint 与官方格式完全兼容。

## 0. 为什么这两个损失直接对准评分

| 任务 | 官方评分口径 | 现状训练损失 | 改法 |
|---|---|---|---|
| C 发动机 | 降低 RMSE，**减少寿命高估**；另报 NASA 非对称分（高估惩罚更重） | 普通平方误差，高估低估等罚 | **非对称平方损失**：高估（pred>true）乘更大权重 α |
| A 气体 | 主指标 **Macro-F1**（各类等权） | 普通交叉熵（按样本等权，受类别不平衡影响） | **类别加权交叉熵**：权重 ∝ 1/类频次 |
| B 轴承 | RMSE / MAE | 平方误差 | 顺带试非对称（方向不定）与 Huber，期望不高 |

## 1. 合规设计：不改官方文件，运行时替换 Model

不在 `base/` 里改任何文件。做法是**子类 + 运行时注入**：

```
WeightedModel(官方 Model)           只重写 fit()，其余（save/load/predict/validate）全部继承
  → checkpoint 字段与官方完全一致，官方 predict.py 能原样加载
生成 patched_train.py（工作目录）    import 官方 baselines.train as T；T.Model = WeightedModel；T.main()
  → 官方 train.py 的全部校验与报告（新目录、保种子/架构、training.json/history.jsonl）原样复用
```

这样只有"每个 batch 的 loss 与梯度"变了，官方的续训约束、记录、预测协议一个都没动。

## 2. 损失公式

**分类（A）类别加权交叉熵**：`w_c = N / (K · n_c)`，再归一化到均值 1，避免改变有效学习率。
`loss = Σ w_{y_i}·(−log p_{i,y_i}) / B`，梯度 `delta = (p − onehot)·w_i / B`。

**回归（B/C）非对称平方损失**：`err = pred − y`（缩放空间，`scale>0` 故符号与原单位一致）
`w_i = α (err>0，高估) / 1 (err≤0)`，`loss = Σ w_i·err² / B`，梯度 `2·w_i·err / B`。
α>1 即"高估罚更重"，α=1 退化为官方损失（用于自证改动可关）。

**Huber（可选）**：`δ` 外线性，抗离群点，用于 B 的对照。

## 4. 实验

每个任务固定种子、10 轮、同一门控（基线仍为官方随包基线值）：

| 任务 | 对照组 | 实验组 |
|---|---|---|
| A | 官方交叉熵（0.7264） | 类别加权 |
| C | 官方平方误差（51.38） | α ∈ {1.5, 2, 3} 非对称 |
| B | 官方平方误差（666.88） | α ∈ {1.5, 2} + Huber |

C 额外报告 **NASA 非对称分**（越低越好）——这是官方会另报的指标，即使 RMSE 不动，
非对称分改善也是实打实的收益。

**采纳阈值**：A 提升需 > 0.004（验证噪声）；B/C RMSE 相对改善 > 1%；
C 的非对称分改善 > 5% 也算有效（因为官方单列此项）。

## 5. 自证与风险

- **α=1 / 权重全 1 时必须与官方损失数值一致**（单测断言），证明改动可关、无隐藏副作用。
- 产出 checkpoint 必须能被**官方未修改的** `Model.load` 与 `predict.py` 加载（单测断言）。
- 风险：非对称损失会牺牲一些对称 RMSE 去换非对称分；若 RMSE 退化超过阈值则不采纳，或只在 C 上采纳。
- 提交材料需声明"修改了训练损失"，并说明不影响推理协议。

## 6. 边界

| 情况 | 处理 |
|---|---|
| 某类在 batch 内缺失 | 权重按全训练集频次预先算好，与 batch 组成无关 |
| 权重导致梯度爆炸 | 权重归一化到均值 1；官方梯度裁剪（norm 5.0）仍生效 |
| 非对称 α 过大不收敛 | 记录为失败变体，不采纳 |
| 官方 train.py 升级 | 子类 + 注入方式不依赖官方内部实现细节，只依赖 `Model` 这个名字 |
